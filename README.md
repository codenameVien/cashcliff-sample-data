# CashCliff 합성 예시 자료

캐시클리프 심사·체험용 합성 금융파일을 제공합니다. 실제 고객·사업자의 정보가 아닙니다.

이 저장소에는 공개용 예시와 사용 안내만 담습니다. 앱 소스 코드, API 키 및 개인 금융자료는 포함하지 않습니다.

## 파일 다운로드

처음 확인할 때는 **간단 예시 2개**를 각각 내려받아 [캐시클리프](https://cashcliff.vercel.app/)에 함께 올려주세요. 아래 링크를 오른쪽 클릭해 '링크를 다른 이름으로 저장'해도 됩니다.

- [간단 예시: 계좌 내역 CSV 다운로드](https://raw.githubusercontent.com/codenameVien/cashcliff-sample-data/codex/publish-samples/cashcliff-quick-account.csv)
- [간단 예시: 정산 내역 XLSX 다운로드](https://raw.githubusercontent.com/codenameVien/cashcliff-sample-data/codex/publish-samples/cashcliff-quick-settlements.xlsx)

파일 선택창에서 두 파일을 함께 선택하거나 순서대로 넣을 수 있습니다. 앱이 파일을 자동으로 불러오지는 않습니다.

## 두 자료가 다른 이유

| 파일 | 담긴 기간·내용 | 계산에 쓰는 방식 |
|---|---|---|
| 계좌 내역 9행 | 2026년 6~8월의 입출금 발췌 | 매월 나가는 임대료·광고비의 반복 패턴을 찾습니다. 과거 입출금은 현재 현금에 다시 더하지 않습니다. |
| 정산 내역 2행 | 2026년 9월 12일·19일 입금 예정 | 아직 받지 않은 정산금 1,850,000원·980,000원을 미래 입금으로 계산합니다. |

두 파일은 같은 달이어야 하는 자료가 아닙니다. 과거 계좌 내역과 앞으로 받을 정산금을 날짜·역할에 맞게 함께 사용합니다. 완료된 정산이 계좌에도 기록되어 있으면 중복 여부를 확인해야 하지만, 간단 예시의 정산은 모두 미완료여서 해당 중복 후보가 없습니다.

계좌 파일은 합성 전체 자료에서 선택한 행입니다. 생략된 거래가 있어 인접 행 잔액 차이가 입출금과 일치하지 않습니다. **파일의 잔액 열은 예측 시작 잔액으로 쓰지 않으며, 현재 현금은 운영 조건에서 직접 입력합니다.**

## 확인 순서

1. 캐시클리프 첫 화면의 파일 처리 안내를 확인하고 동의한 뒤 간단 예시 두 파일을 선택합니다.
2. 임대료 상가 3건은 `임대료`, META 광고비 3건은 `광고비`로 분류합니다. AI 분류는 별도 동의 후 제안을 받아 직접 적용하는 선택 기능입니다. 실패해도 수동 분류로 계속할 수 있습니다.
3. 운영 조건에서 예측 시작일 **2026-09-08**, 기간 **30일**, 현재 현금 **2,000,000원**, 안전잔액 **1,000,000원**을 입력합니다.
4. 시작일을 정한 후 반복 후보인 광고비 **345,000원 / 9월 14일**, 임대료 **1,200,000원 / 10월 5일**을 확인하고 둘 다 포함합니다.
5. 예정 거래에 `장비 구매`, **출금 3,000,000원**, **2026-09-16**을 추가한 뒤 결과를 확인합니다.

위 조건으로 일반 파일 업로드부터 계산까지 확인한 결과입니다.

| 확인할 값 | 결과 |
|---|---:|
| 안전잔액 아래로 처음 내려가는 날짜 | 2026-09-16 |
| 그날 예상 잔액 | 505,000원 |
| 안전잔액 대비 부족액 | 495,000원 |
| 예측 기간 중 최저 잔액 | 2026-10-05, 285,000원 |

9월 12일 정산금 1,850,000원이 들어오고, 9월 14일 광고비 345,000원과 9월 16일 장비 구매비 3,000,000원이 나갑니다. 따라서 9월 16일 잔액은 `2,000,000 + 1,850,000 - 345,000 - 3,000,000 = 505,000원`입니다. 날짜·반복 포함 여부·분류를 다르게 선택하면 결과도 달라집니다.

## 범위와 개인정보

예시 파일은 KB형 계좌 CSV·네이버페이형 정산 XLSX 구조의 **합성 테스트 파일**입니다. 특정 금융회사·채널의 모든 실제 다운로드 파일과 호환된다는 뜻이 아닙니다.

다운로드한 합성 파일도 일반 업로드와 동일하게 처리합니다. 파일명만 보고 신뢰 자료로 간주하지 않습니다. AI 분류 요청에는 식별정보를 가린 거래 설명만 사용하며, 원본 파일을 보내지 않습니다. 업로드 경로의 결과 설명·가정 수정·정책자금 비교는 결정론 계산과 수동 기능을 사용합니다. 이 예시는 금융상품 추천이나 세무·회계 자문이 아닙니다.
