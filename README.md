# 잔고미리 예시 파일

**[예시 파일 다운로드 ↓ (ZIP)](https://github.com/codenameVien/cashcliff-sample-data/releases/download/jangomiri-v1/jangomiri-sample.zip)**

1. 위 링크를 눌러 ZIP을 받고 압축을 풀어주세요.
2. [잔고미리 열기](https://jangomiri.vercel.app/) → 파일 읽기 동의 → **파일 고르기**를 누르세요.
3. 압축 안의 **CSV와 XLSX 두 파일을 함께** 선택하세요.

CSV는 과거 계좌 내역, XLSX는 앞으로 받을 정산금입니다. 모두 가상의 자료입니다.

**[입력할 금액·날짜와 결과 확인하기 →](GUIDE.md#확인-순서)**

ZIP이 열리지 않으면: [계좌 CSV](https://github.com/codenameVien/cashcliff-sample-data/releases/download/jangomiri-v1/cashcliff-quick-account.csv) · [정산 XLSX](https://github.com/codenameVien/cashcliff-sample-data/releases/download/jangomiri-v1/cashcliff-quick-settlements.xlsx)
